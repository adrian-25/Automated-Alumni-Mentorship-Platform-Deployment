# Automated Alumni Mentorship Platform Deployment

A final-year CSE DevOps project that delivers a small Spring Boot application and a reproducible path from source control through testing, packaging, containerization, and Ansible provisioning.

## Tech stack

Java 17, Spring Boot 3, Thymeleaf, H2, Maven, JUnit 5, Selenium WebDriver, Tomcat 10, Jenkins, Docker, and Ansible.
